## On your phone in GitHub

1. Read [the mobile study guide](study-guide.md).
2. Open [review.md](review.md), tap the pencil/edit button, and write under **My reply**.
3. Save your edits as a commit or proposed change. These replies are then part of the repo.

## HTML versions

- [Full study guide](study-guide.html): original explanations, pseudocode, and 13 embedded offline flowcharts.
- [Companion worksheet](review.html): blank reply fields, local browser retention, and Markdown export.

GitHub displays HTML as source rather than running it. Open the raw/downloaded HTML in a browser to use it. The HTML worksheet cannot write to GitHub; export or copy its notes into review.md. Browser retention is device-specific and may be unavailable for local files or private browsing.

For a local rendered view, run `python3 -m http.server 8000 --directory docs/next-steps/portfolio-review` from the repository root and open the server in your browser. This does not publish the docs. Public hosting can be considered separately.

The HTML is the original guide; study-guide.md is a reading companion. Future substantive edits should keep both in agreement.
